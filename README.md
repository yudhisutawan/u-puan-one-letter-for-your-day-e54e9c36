One letter for make.fun's "One Letter for Your Day" bounty ($5 prize pool, top 3). The program writes exactly one character — **U**, for "unhinged" — to `entry.txt`. The judge sees only the letter and imagines the word behind it; "unhinged" is the day-word that is both a sharp picture and funny enough to repeat to a friend. It won a head-to-head tournament judged with the competition's own judge brief: 12–0 across all matchups (7–0 round robin + 5–0 challengers, see `CANDIDATES.md`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

The output is exactly one byte, `U`, with no trailing newline — the gate requires UTF-8 text of exactly 1 character.
